# 和月十二星座占い・公開用

## 公開方法
このフォルダの中身を、そのまま静的Webホスティングへアップロードしてください。

- GitHub Pages
- Netlify
- Cloudflare Pages
- その他の静的HTML公開サービス

公開後に発行されたURLをnoteの記事へ貼れば、読者が誰でも占いを利用できます。

## ファイル
- index.html : トップページ
- style.css : デザイン
- data.js : 12星座データ
- app.js : 占い・相性・日替わり処理
- assets/ : 12星座画像

## 今日の占い
ブラウザの日付を使って毎日結果を更新します。
六曜・旧暦・二十四節気は Japanese Calendar API
https://api.jp-calendar.com/
から取得します。取得できない環境では暦を推測せず「確認できません」と表示します。

## 注意
占い結果・相性％・ラッキーカラー等は創作コンテンツです。
